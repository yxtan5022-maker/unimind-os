# UniMind: Middleware-фреймворк для гибридных квантово-классических вычислений

[English](README.md) | [简体中文](README.zh-CN.md) | Русский

UniMind — это **пользовательский middleware-фреймворк**, связывающий классические AI-нагрузки с гетерогенными квантово-классическими бэкендами. Он не претендует на роль операционной системы: LLM-слой оркестрации полностью работает в пользовательском пространстве, поверх существующей классической ОС, и позиционируется как *планировщик задач*, а не *исполнитель задач*.

## Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **AI как оркестратор** | Пользовательская LLM-маршрутизация намерений с sandbox-валидацией и детерминированным **резервным режимом на основе правил** (шаблоны Bell-состояний / VQC) после 3 неудачных попыток LLM |
| **Препроцессинг Unibit** | Классическое скользящее окно оценки частоты + sinc-сглаживание, формирующее параметры стандартного квантового углового кодирования (`theta = 2 * arcsin(sqrt(w))`) |
| **Многобэкендное отображение** | Единый API-роутинг к бэкендам Classical (Python/Rust), Qiskit и CUDA-Q |
| **Осведомлённость о топологии** | C++17 определение оборудования в рантайме (ядра CPU, память, ОС, архитектура), сериализуемое в JSON |
| **Самовосстановление** | Контур мониторинга и обратной связи, возвращающий трассировки выполнения оркестратору для исправления |

## Валидация и бенчмарки

Все приведённые ниже числа получены запуском экспериментов из `experiments/` на этой машине (Windows, x86_64, Python 3.12, Rust-ядро собрано командой `cargo build --release`). Это **воспроизводимые реальные данные**, а не симуляция.

### Эксперимент A — Математическая валидация (8192 выстрела AerSimulator)

Для целевых весов Unibit `w` мы готовим состояние одного кубита через `theta = 2*arcsin(sqrt(w))`, запускаем 8192 выстрела на идеальном Qiskit AerSimulator и сравниваем эмпирическое ожидание Паули-`Z` `<Z> = 1 - 2*P(1)` с теоретическим значением `1 - 2w`.

```bash
python experiments/test_math_verification.py
```

| Цель w | P(1) эмпир. | `<Z>` теория | `<Z>` эмпир. | \|откл.\| |
|---------:|---------------:|-------------:|----------------:|--------:|
| 0.1000 | 0.095459 | 0.800000 | 0.809082 | 0.009082 |
| 0.3000 | 0.296875 | 0.400000 | 0.406250 | 0.006250 |
| 0.5000 | 0.505493 | 0.000000 | -0.010986 | 0.010986 |
| 0.7000 | 0.704590 | -0.400000 | -0.409180 | 0.009180 |
| 0.9000 | 0.901733 | -0.800000 | -0.803467 | 0.003467 |

**Максимальное абсолютное отклонение `|<Z>_эмпир. - <Z>_теория| = 0.0110 < 0.05` (ПРОЙДЕНО).** Эксперимент использует фиксированное зерно симулятора (`seed_simulator=42`), поэтому приведённые числа точно воспроизводимы между запусками. Эмпирические вероятности измерения сходятся к теоретическим весам в пределах биномиальной дисперсии выборки, что подтверждает корректную инициализацию амплитуд квантовых состояний классическим конвейером предобработки.

## Структура репозитория

```
unimind-os/
|-- umos_py/           # Ядро Unibit-движка (Python, авто-загрузка Rust FFI)
|-- bridge/            # AI-оркестратор, резерв по правилам, самовосстановление
|-- quantum/           # Многобэкендное отображение квантовых схем QUnibit
|-- core/              # Rust-ускоренный Unibit-движок (FFI)
|-- kernel/            # C++ топологический маппер (определение оборудования)
|-- gui/               # Графический интерфейс Tkinter
|-- experiments/       # Воспроизводимые эксперименты (мат. валидация, бенчмарк)
|-- tests/             # pytest-набор
|-- docs/              # Спецификация дизайна + тех. документ
|-- example/           # Демонстрации proof-of-concept
|-- .github/workflows/ # CI-конвейер
|-- CMakeLists.txt     # Конфигурация сборки C++
|-- Makefile           # Автоматизация сборки
|-- pyproject.toml     # Конфигурация Python-пакета
|-- requirements.txt   # Зависимости Python
|-- run.py             # Точка входа
|-- build.py           # Скрипт сборки в один вызов
```

## Быстрый старт

```bash
# Клонирование и установка
git clone https://github.com/yxtan5022-maker/unimind-os.git
cd unimind-os
pip install -e .

# Запуск основных демо
python run.py
python example/proof_of_concept.py

# Запуск отображения квантовых схем (требуется qiskit)
pip install -e ".[quantum]"
python -c "from quantum.qunibit import demo; demo()"

# Воспроизведение экспериментов
python experiments/test_math_verification.py   # Валидация Qiskit на 8192 выстрелах
python experiments/benchmark_unibit.py         # Бенчмарк Python vs Rust FFI

# Запуск всех тестов
python -m pytest tests/ -v

# Сборка Rust-ядра (авто-загружается Python для ускорения)
cd core && cargo build --release && cd ..

# Сборка C++ ядра (топологический маппер)
cmake -S . -B build
cmake --build build --config Release

# Сборка в один вызов
python build.py
```

## LLM-оркестрация

Установите переменные окружения для включения реальной LLM-маршрутизации намерений:

```bash
export UMOS_LLM_API_KEY="sk-..."
export UMOS_LLM_BASE_URL="https://api.openai.com/v1"  # или Ollama и т.д.
export UMOS_LLM_MODEL="gpt-4o-mini"                    # по умолчанию

python bridge/umos_link.py
```

Без ключа — или после 3 неудачных попыток LLM-инференса — оркестратор переключается на детерминированный **диспетчер на основе правил** (`rule_based_fallback`): намерения с *entangle*/*bell* формируют шаблон подготовки Bell-состояния, а *classify*/*vqc* — базовый шаблон вариационной квантовой схемы.
