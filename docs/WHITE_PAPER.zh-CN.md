# UniMind 技术白皮书

[English](WHITE_PAPER.md) | 简体中文

UniMind 是一个**用户空间量子-经典中间件研究原型**。它把经典预处理表示（Unibit）与 LLM 驱动的编排器配对，规划任务执行；它没有虚构的"操作系统"、没有虚拟内存扩展、没有内核绕过。本文档描述代码实际实现的内容、背后的数学以及实测证据。

## 1. Unibit：面向量子角度编码的经典预处理

Unibit 把二进制序列映射为标准的单比特角度编码所需的旋转参数。变换分三步，Python 与 Rust FFI 引擎中的实现完全一致。

**第 1 步——滑动窗口频率（论文式 2）。** 每个比特被替换为以窗口半宽 `window_delta` 为中心的邻域内 1 比特的局部频率：

$$w_i = \frac{1}{|W_i|} \sum_{j \in W_i} b_j$$

**第 2 步——sinc 平滑（论文式 3）。** 加权信号乘以由序列长度 `n` 与固定相移 `phi` 缩放的 sinc 包络：

$$s_i = w_i \cdot \operatorname{sinc}\!\left(\frac{(i+\phi)\,\pi}{n}\right)$$

**第 3 步——折叠（论文式 4）。** 平滑信号按折叠阈值 `tau` 重新阈值化为离散值：

$$\text{collapse}(s_i) = \begin{cases} 1 & |s_i| > \tau \\ 0 & \text{otherwise} \end{cases}$$

随后对每个参数准备单比特态，旋转角 `theta = 2*arcsin(sqrt(w_i))`，使激发态测量概率等于 `w_i`。

## 2. 量子映射

映射引擎（Qiskit）构建多比特电路，每个经典比特对应一个参数化 `R_y(theta)` 门，外加可选的测量。仿真使用理想 AerSimulator；配套实验验证经验测量频率在二项采样方差范围内收敛于理论权重。

## 3. LLM 驱动的编排（用户空间）

编排器解释自然语言任务规范、规划执行并把计划分派给本地执行工具。它**仅在用户空间**运行：

- LLM 输出在受限命名空间沙箱（`SandboxExecutor`）中校验：白名单放行安全内建函数，并在执行前通过静态分析拒绝风险模式（`open(`、`eval(`、`exec(`、`os.`、`subprocess` 等）。
- 当 LLM 不可用或生成的计划失败时，基于规则的回退执行简单的意图动作（fold、compute、status）。
- 不支持的意图动作返回诚实的"不支持"响应，而非伪造结果。

## 4. 硬件检测

`kernel/topo_mapper.cpp` 是一个 C++17 程序，检测主机的逻辑/物理核心数、操作系统、架构和总内存，并在标准输出上以 JSON 输出结果。它不执行任何"自适应性能"逻辑；它只是被编排器消费的硬件探针。
